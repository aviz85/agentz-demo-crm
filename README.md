# CRM לידים — הדגמת AgentZ

אפליקציית הדגמה למועדון AgentZ. זו סימולציה מדויקת של אפליקציית Next.js קטנה, ולא פרויקט של לקוח אמיתי.

העמוד הראשי מציג רשימה סטטית של שלושה לידים בדויים (`אלון דמו`, `מיכל דוגמה`, `תמר סימולציה`). אין כאן מסד נתונים, ואין סודות או פרטים אמיתיים.

## מטרת הדמו

הריפו הזה משמש בהדרכה כדי להראות לופ פיתוח מלא:

1. קוד ב-GitHub
2. פריסה אוטומטית ב-Vercel מחיבור Git (ערוץ Production על `main`, ותצוגות מקדימות לכל Pull Request)
3. עבודה של סוכן ענן של Cursor על אותו ריפו

חיבור מסד נתונים (Prisma Postgres דרך ה-Marketplace של Vercel) יודגם בנפרד, ולא נכלל בשלב הזה.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז פותחים את [http://localhost:3000](http://localhost:3000).

בנייה לייצור:

```bash
npm run build
npm start
```

## מחסנית

- Next.js (App Router) ו-TypeScript
- ממשק עברי מלא, מימין לשמאל
- רשימת לידים סטטית בקובץ `lib/leads.ts`
